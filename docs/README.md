## 尚待产品确认的决策

这些问题不阻塞基础架构，但必须在对应功能开始前确定：

- 首发是单用户、团队空间，还是公开注册的多租户产品。
- 模型供应商、Embedding 模型、预算上限以及是否允许资料发送到第三方模型。
- 单文件大小、页数、资料库容量和支持语言的产品上限。
- 文件保存期限、账号注销后的删除时限以及是否需要企业级审计。
- Quiz 是否只做练习，还是需要正式考试、防作弊和证书能力。
