# ADR-0002：LangGraph 证据编排与 PostgreSQL 业务检查点

- 状态：Accepted
- 日期：2026-09-27
- 范围：组合学习 Agent 的持久化、等待及恢复。

## 背景

现有系统使用 asyncpg/SQLAlchemy、最小权限运行角色、Alembic 和 PostgreSQL 任务租约。加入完整图 saver 将额外增加连接池、框架 schema 和与业务结果不一致的提交边界；图状态也容易复制证据正文。

## 决策

LangGraph 在基础设施层执行显式证据工具图。应用阶段采用 `agent_runs` 状态机及 `agent_stage_executions` 调用回执持久化，统一使用现有连接池和工作区授权。不采用进程内存作为持久化，不直接持久化完整图状态。

所有调用先短事务保存 `calling` 并预留累计预算，事务外访问模型，再保存 `returned` 结果与用量。租约失效且存在 `calling` 时关闭为 `blocked / RUN_RESULT_UNKNOWN`，禁止盲目重发；只有保存了结果的请求可以回放。阶段成果、下一步、调用数据清理原子提交，重复领取不重复发布。

等待输入不占 Worker 或数据库事务。Quiz 与绑定 attempt 原子发布；真实评分事务同时把关联运行排入后续阶段，相当于业务事务内的持久化恢复信号。无需第二个事实源或额外 Outbox。外部请求不承诺只收费一次。

私有返回结果成功发布即清除；到期由 Worker 或经授权的运行查询清理。正文、Prompt、返回载荷不写日志、不出 API。文档版本删除传播到运行和回执；框架及 LangSmith 追踪显式关闭，保留现有脱敏计量。

## 影响

应用拥有恢复语义，框架提供节点和条件路由。当前不是框架原生 `interrupt()`/saver 恢复。未来引入标准 saver 需新增迁移、权限、连接预算、运行到 thread 的授权映射及删除测试；仍必须保留业务幂等回执与未知请求保护。LangChain 模型适配器按供应商需求选择，目前不替换已有可测端口。

回滚使用应用开关停止创建新运行并让兼容 Worker 处理已有记录；生产不执行删除运行表的 downgrade。
