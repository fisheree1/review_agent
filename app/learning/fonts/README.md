Noto Sans SC is used to embed Chinese and English glyphs in generated study PDFs.
`NotoSansSC-Regular.ttf` is the 400 weight static instance of the upstream
`Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf` from
[notofonts/noto-cjk](https://github.com/notofonts/noto-cjk).
